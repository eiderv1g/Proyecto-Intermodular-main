# Proyecto Intermodular 1º ASIR

## Índice

El Proyecto Intermodular de 1º es una iniciativa de Prometeo by The Power pensada para que entiendas mejor para qué sirve todo lo que estás aprendiendo en primero y cómo se conecta entre sí.

En muchas ocasiones, los módulos se ven como asignaturas sueltas: programación por un lado, bases de datos por otro, sistemas por otro… y es normal que te preguntes:

- “¿Y todo esto cómo se une?”  
- “¿Para qué me va a servir en el mundo real?”  

Este proyecto nace precisamente para responder a esas preguntas.

A través del Proyecto Intermodular, podrás trabajar en un proyecto real que combine lo que ves en varios módulos y que además te sirva para empezar a crear tu portfolio profesional desde primero. Es decir, cosas que luego podrás enseñar en entrevistas, prácticas o procesos de selección.

Además, este proyecto te ayudará a llegar mucho más preparado al Proyecto Intermodular de 2º, que sí será una asignatura oficial.

Importante: este proyecto no es una asignatura, pero puedes usarlo como base para continuar el año que viene.

---

## Módulos de 1º de ASIR y su conexión

En primero de ASIR cursas varios módulos que, aunque se imparten por separado, forman parte de un mismo perfil profesional: administrador/a de sistemas informáticos y redes.

### Módulos

- 0371 – Fundamentos de hardware  
- 0372 – Gestión de bases de datos  
- 0369 – Implantación de sistemas operativos  
- 0373 – Lenguajes de marcas y sistemas de gestión de información  
- 0370 – Planificación y administración de redes  
- CMO – Módulo Profesional Optativo  
- 1709 – Itinerario personal para la empleabilidad I  

### Conexión entre módulos

Cada módulo aporta una parte distinta del sistema:

- Fundamentos de hardware → definición de equipos  
- Sistemas operativos → instalación y configuración  
- Redes → diseño de la red  
- Bases de datos → gestión de la información  
- Lenguajes de marcas → documentación técnica  
- Módulo optativo → especialización  
- Empleabilidad → perfil profesional y portfolio  

El proyecto te permite ver todo como un único sistema: la infraestructura tecnológica completa de una empresa.

## Desarrollo integral de una infraestructura TI

El proyecto consiste en diseñar, desplegar y documentar una infraestructura tecnológica completa para una empresa real o simulada.

### Objetivos

- Análisis de necesidades tecnológicas  
- Diseño de la infraestructura  
- Selección de hardware  
- Implantación de sistemas operativos  
- Configuración de servicios  
- Gestión de usuarios y permisos  
- Diseño de red  
- Gestión de datos  
- Documentación técnica  
- Control de versiones  
- Presentación profesional  

### Elementos de la infraestructura

- Servidores  
- Equipos cliente  
- Red local  
- Servicios de red  
- Sistemas operativos  
- Usuarios y permisos  
- Almacenamiento  
- Copias de seguridad  
- Monitorización básica  
- Servicios en la nube  

No se busca un sistema perfecto, sino uno coherente y bien planteado.
