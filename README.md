# CYBERFORGE - PROYECTO INTERMODULAR

**Equipo**: Sergio Gallardo Marchal, Miriam Ocaña Pérez-Cerdá, Antonio José Rossi Bersabé.

---

**CyberForge** **es un proyecto orientado al diseño e implantación de una infraestructura IT para un centro de formación especializado en ciberseguridad.** 

Busca crear una base sólida mediante el desarrollo de laboratorios prácticos realistas y el despliegue de una infraestructura virtualizada segura. También pretende generar materiales propios, asegurar la calidad mediante certificaciones y definir KPIs para medir rendimiento y satisfacción.

CyberForge está dirigido a:

- Estudiantes y recién graduados
- Profesionales en reconversión laboral
- Profesionales de ciberseguridad en activo
- Entusiastas autodidactas

Todos ellos con interés en una formación práctica orientada a escenarios reales.

El proyecto se apoya en:

- **Virtualización:** VirtualBox, VMware, Proxmox
- **Sistemas operativos:** Ubuntu Server/Desktop, Windows 11 Pro, Kali Linux
- **Redes:** Cisco Packet Tracer, VLANs
- **Cloud:** AWS (EC2, S3, IAM, NBL)
- **Desarrollo y documentación:** VS Code, XML, HTML, CSS, JSON, Markdown, Notion
- **Gestión y control:** GitHub, Clonezilla

CyberForge es un proyecto colaborativo desarrollado por tres integrantes (**Sergio, Miriam y Antonio**), donde la cooperación ha sido clave para integrar conocimientos, compensar debilidades individuales y construir un sistema complejo y cohesionado. El trabajo en equipo ha fortalecido habilidades técnicas y organizativas, con la ambición de seguir evolucionando el proyecto en el futuro.
