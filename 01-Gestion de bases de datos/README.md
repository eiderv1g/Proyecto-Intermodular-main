# CYBERFORGE - Gestión de Base de Datos

**Equipo**: Sergio Gallardo Marchal, Miriam Ocaña Pérez-Cerdá, Antonio José Rossi Bersabé.

---

En el módulo de Gestión de Base de Datos se ha diseñado y creado una base de datos acorde a las necesidades que requería Cyberfoge. Para ello, se ha tenido en cuenta la capacidad de poder hacer consultas útiles, almacenar información teniendo en cuenta los datos que la empresa necesita actualmente pero pudiendo escalarse de ser necesario en el futuro y la administración de la misma.
